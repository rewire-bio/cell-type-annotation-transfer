# Compact reference recovery tools

These maintained operational tools verify frozen public metadata and recover a separate local reference only from independently generated candidates with exact original hashes and sizes. They do not acquire data, fit models, predict or score. The unchanged scientific comparator and paper scripts run under the original resource limits.

See the repository README and release instructions for the pinned scientific revision, auxiliary revision, downloads and executable commands.
